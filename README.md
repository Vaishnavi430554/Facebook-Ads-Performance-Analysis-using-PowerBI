# Facebook Ads Performance Dashboard

## Project Overview
This project presents an interactive Power BI dashboard built to analyze Facebook Ads campaign performance. The dashboard provides insights into ad spend, impressions, clicks, conversions, CTR, CPC, and ROI, helping marketers evaluate campaign effectiveness and make data-driven decisions.

---

## Objective
- Analyze Facebook Ads campaign performance.
- Identify the best-performing audience segments.
- Compare campaign-wise spending and ROI.
- Track important marketing KPIs through an interactive dashboard.

---

## Tools Used
- Power BI
- Microsoft Excel
- Power Query
- DAX

---

## Dataset
The dataset contains **68,158,184 Facebook Ads records** with information such as:
- Campaign ID
- Age Group
- Gender
- Impressions
- Clicks
- Conversions
- Spend
- CTR
- CPC
- ROI

---

## Dashboard Features
- KPI Cards for Total Spend, Impressions, Clicks, CTR, CPC, and ROI
- Campaign-wise Spend Analysis
- Impressions by Age Group
- Clicks by Gender
- Ad Performance Funnel
- Campaign-wise ROI Analysis
- Interactive Filters (Age Group, Gender, Campaign ID)

---

## Key Insights
- Analyzed **68.1 million Facebook Ads records**.
- Generated **79 million impressions** and **11,674 clicks**.
- Total advertising spend was **$19.62K**.
- Overall Click Through Rate (CTR) was **1.49%**.
- Average Cost Per Click (CPC) was **$1.68**.
- The **30–34 age group** generated the highest number of impressions.
- **Male users accounted for 85.57% (10K) of total clicks**, while **female users accounted for 14.43% (2K)**.
- Campaign **1178** contributed the highest advertising spend.
- Dashboard enables quick analysis of campaign performance and ROI.
